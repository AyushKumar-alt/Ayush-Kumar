## 🔥 Featured Projects

### 🧠 [Deep Model Compression — RL-guided Knowledge Distillation](https://github.com/AyushKumar-alt)
> *Research project | Jan 2026 – Apr 2026*

Designed a novel **RL-KD framework** where a DQN agent dynamically selects the KD loss weighting coefficient α per training epoch — moving beyond static hyperparameter tuning. Compressed **VGG16-BN (65M params) → MobileNetV2 (3.4M params)** achieving **19–20× compression** with **92.24% CIFAR-10 accuracy** and **47.86% Tiny-ImageNet** (+1.33% over manual KD baseline).

`PyTorch` `DQN` `Knowledge Distillation` `Optuna` `Ax BO` `CIFAR-10` `Tiny-ImageNet`

---

### 🤖 [ARJUNA — Adversarial Robustness Gym for Embodied AI](https://github.com/AyushKumar-alt)
> *Feb 2026 – Apr 2026*

OpenAI Gym-compatible environment for stress-testing RL agent perception under adversarial sim-to-real gaps. Features a **stochastic auto-curriculum** generating OOD scenarios. Released **Arjuna-OOD v1** dataset with custom reward metrics; live FastAPI simulation deployed on **Hugging Face Spaces**.

`Python` `OpenAI Gym` `FastAPI` `Hugging Face Spaces` `Computer Vision` `RL` `OOD Robustness`

`Node.js` `Prisma` `OpenAI API` `Exotel IVR` `FastAPI` `Civic Tech`
